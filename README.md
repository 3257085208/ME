# QQ.SG 个人网站 · v8 · 电影感版本

解压后双击 index.html 即可打开。请保持目录结构；也可以将整份目录放到静态网站服务器。无需构建或安装依赖。

## 连续滚动页面

首页 → 作品引言 → 聶.NET 博客 → NIE-SLA → NIE Theme → 域名与 ASN 印记 → 关于我。

桌面端以整屏章节连续推进。顶部导航是当前页面的章节锚点，全部内容直接向下滚动即可看到。

本版重新编排字体、画面尺度与滚动节奏：大号衬线标题跨过作品画面，黑白反相叠印；画面展开后留出停顿。章节通过浏览器原生 sticky 布局在同一视窗重叠，使用透明度交接，标题错开退场与入场。没有逐帧位置补偿或整页缩放；结尾再次回到人像与签名。

四个章节仍有各自的滚动过程，向上滚动时可以倒放：

- 博客：稿纸封面沿左侧翻开，露出真实博客页面。
- NIE-SLA：扫描线逐步揭开监控界面，再画出信号轨迹。
- NIE Theme：四块界面切片沿不同方向移动，最后拼回完整截图。
- 印记：五个域名依次展开，连接线从 ASN 向各个地址画出；轨道和背景同时移动。

手机端使用自然文档滚动，翻页、扫描和拼合根据画面进入视窗的位置推进，域名沿竖线逐个展开。遵循系统“减少动态效果”设置，显示完成状态并关闭签名动画。页面没有接管滚轮或强制翻页。

## 文件

- index.html：完整页面与内容。
- scroll.css：桌面、手机布局及视觉效果。
- scenes.css：四个章节各自的构图和动画样式。
- cinema.css：v8 的字号、叠印、画面尺度、转场与响应式调整。
- scroll.js：滚动动效、章节进度、入场与签名动画。
- portrait-retouched-v4.png：保留用户喜欢的美化人像，并对鼻尖补光。
- assets/：真实项目界面截图。
- SOURCES.md：内容与截图来源。
- original/：用户最初提供的网页与美化人像备份。

签名使用原版速度：长度乘 2.65，长笔画 240–1150 毫秒，点笔画 90 毫秒，笔间停顿 40 / 68 毫秒。

作品截图是截取时的界面，不是实时监控。域名按用户提供的信息列出，不代表每个域名均配置了网页服务。IDC 系统按用户要求未展示。
