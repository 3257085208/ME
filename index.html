独立开源项目

聂.NET - 高性能纯静态博客系统
2026.01 至今
独立全栈开发 / 架构设计
不满于传统博客系统的臃肿与受限，我从零开始用 Python 手写了一套静态页面生成器（SSG）。
  • 底层构建： 使用 Python 编写核心逻辑，实现 Markdown 文件的毫秒级解析、渲染与元数据提取。
  • 前端体验： 零依赖手写响应式前端 UI，深度整合自适应暗黑模式、无刷新状态切换。
  • CI/CD 部署： 结合 GitHub 仓库，利用 Cloudflare Pages 实现了代码推送后的自动化边缘节点构建与全球分发，极大提升了访问速度。
